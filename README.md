# InfiniteGithubUpstreamSync（IfGhUS）

把任意 GitHub 仓库设为「上游」，按设定间隔自动拉取并覆盖同步到本地：**同名文件以远程为准覆盖，远程新增的复制过来，本地独有的文件保留不删**。支持托盘常驻、开机自启、排除规则、GUI 设置与自动更新。

---

## 快速开始

1. 把本目录**整个**放到任意位置（路径可含中文）。
2. 双击 `双击启动同步.bat`，选 **1**。
3. 按提示输入：
   - 上游仓库地址，必须形如 `https://github.com/用户名/仓库名`
   - 同步间隔（分钟，必须为正整数）
4. 之后托盘常驻、开机自启，无需再开命令行。

> 首次运行会生成 `sync-upstream.config.json` 保存配置；想重新配置，删掉它再运行即可。

| 项 | 要求 |

## GUI

托盘右键「回到控制台」选 8，或命令行 `.\InfiniteGithubUpstreamSync.ps1 -GUI` 打开。含：仓库地址与间隔设置、排除规则列表（可从资源管理器多选文件）、立即同步、启动/停止托盘、自启开关、实时状态与日志、检测更新 / 更新到最新版。

## 排除规则

命中的上游文件**不覆盖、不新增**，本地原样保留。写在 `sync-upstream.config.json` 的 `Excludes` 数组，支持通配：

| 写法 | 效果 |
|---|---|
| `node_modules` | 任何同名目录整体跳过 |
| `*.log` | 按文件名通配 |
| `build\*` | 按路径通配 |

管理入口：控制台菜单 7，或 GUI 的排除规则列表。同步统计会显示「排除 N 个」。

## 同步规则

| 情况 | 行为 |
|---|---|
| 同名文件内容不同 | 以远程为准覆盖，旧文件自动备份 |
| 远程新增文件 | 复制到本地 |
| 本地独有文件 | 完全不动 |
| 命中排除规则 | 跳过 |
| 内容相同 | 跳过，不写盘 |

## 自动更新

工具从内置更新源读取最新 tag，与当前版本比较后按需更新：下载 → 语法校验 → 备份到 `.sync-script-backup\` → 替换 → 重启托盘（失败自动回滚）。更新后本地版本号自动跟随 tag。

## 版本与发布

版本号形如 `X.Y.Z`。每次 push 到 `main`，[`tag-release.yml`](.github/workflows/tag-release.yml) 会：

1. 取现有最大 tag，按十进制进位递增：`Z+1`；Z 满 10 → Z 归 0、`Y+1`；Y 满 10 → Y、Z 归 0、`X+1`
2. 把新版本号写回两个 `.ps1` 的 `$ToolVersion`
3. 提交（带 `[skip ci]`，避免循环触发）、打 tag、发布 release

因此**发版不需要手动改版本号**，push 即可。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击 bat 提示找不到 PowerShell / 中文乱码 | bat 为纯 ASCII + CRLF，请保持原文件编码，不要用编辑器另存为 UTF-8 |
| 同步失败 | 右键托盘 → 查看实时日志；确认 Git 已安装、仓库地址可访问 |
| 想换仓库或间隔 | 删除 `sync-upstream.config.json`，重新运行菜单 1 |
| 想彻底卸载 | 菜单 3（停止 + 取消自启），再删除本目录 |
| 托盘图标不见了 | 点任务栏 `^` 展开隐藏图标 |
